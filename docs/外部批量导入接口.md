# 外部批量导入接口约定

本系统只通过 REST 与外部「批量导入工具」交互，不管理对端进程。
接口路径、请求体、状态字段均可通过 `app.external.*` 配置，正式契约确认后只改配置或换实现。

## 1. 配置

```yaml
app:
  external:
    enabled: true
    base-url: http://batch-import-host:9000
    dispatch-path: /api/jobs
    status-path: /api/jobs/{externalJobId}
    stop-path: /api/jobs/{externalJobId}/stop
    callback-token: change-me
    callback-base-url: http://127.0.0.1:8080
    connect-timeout: 5s
    read-timeout: 30s
    poll-interval: 5s
    poll-max-duration: 2h
```

- `enabled=false` 时使用 `DisabledBatchImportClient`：预检给出 `EXTERNAL_DISABLED` 警告，派发返回 `EXTERNAL_UNAVAILABLE`，本地文件夹与 input CSV 仍会生成，便于联调。
- 实现类：`ac.core.service.external.HttpBatchImportClient`。

## 2. 派发

`POST {base-url}{dispatch-path}`

```json
{
  "requestId": "8b1f0c2e-...",
  "productType": "IRS",
  "workingFolder": "E:\\otc\\data\\tenants\\hkex-otc\\jobs\\2026\\11\\8b1f0c2e",
  "inputFile": "E:\\otc\\data\\tenants\\hkex-otc\\jobs\\2026\\11\\8b1f0c2e\\input\\8b1f0c2e.csv",
  "rowCount": 12,
  "callbackUrl": "http://127.0.0.1:8080/api/external-jobs/8b1f0c2e/callback"
}
```

响应体（任一字段即可识别外部任务 id）：`jobId` / `externalJobId` / `id` / `executionId`。

- `requestId` 等于本地任务 id，用于幂等。
- 派发前本地已写入 `input/{jobId}.csv` 与 `input/manifest.json`。
- 连接失败 → 本地状态 `FAILED`，保留 payload 与错误信息，可人工重新派发。

## 3. 状态

`GET {base-url}{status-path}`（`{externalJobId}` 替换为外部任务 id）

响应体字段识别顺序：`status` / `state` / `jobStatus`；附加信息：`message` / `error` / `detail`。

| 外部值 | 本地状态 |
| --- | --- |
| `queued`、`pending` | `DISPATCHED` |
| `running`、`processing`、`in_progress` | `RUNNING` |
| `success`、`succeeded`、`completed`、`done`、`finished` | `SUCCEEDED` |
| `failed`、`error` | `FAILED` |
| `stopped`、`cancelled`、`canceled` | `STOPPED` |
| 其他 | `UNKNOWN`（原文保留在 `last_response`） |

轮询由 `ExternalJobPoller` 每 5 秒执行；超过 `poll-max-duration` 置 `UNKNOWN`，允许手动刷新。

## 4. 停止

`POST {base-url}{stop-path}`，返回 2xx 视为已确认。

本地立即置 `STOPPED`；若对端未确认，`message` 记录“未确认”。停止后仍允许扫描已生成的产出。

## 5. 回调（可选）

`POST /api/external-jobs/{id}/callback`

```json
{ "token": "change-me", "status": "success", "message": "done" }
```

- `token` 必须等于 `app.external.callback-token`（留空则不校验）。
- 状态映射同上；终态写入 `finished_at`。

## 6. 产出文件

- 目录：`{workingFolder}`，跳过 `input/`、隐藏文件、非 `.csv`。
- 单次扫描 ≤ 200 个文件，单文件 ≤ 100MB。
- 以 `sha256` 去重：已登记的文件不会重复导入。
- 每个 CSV 生成 `external_output` 记录，并尝试解析为 `origin=EXTERNAL_OUTPUT` 的批次与用例。
- 产出用例不出现在 `/api/batches`（默认过滤）与主用例列表，只出现在 `/outputs`。
- 解析失败时文件仍可下载，`status=FAILED` 并给出原因。

## 7. 联调建议

1. 先用 `enabled=false` 走一遍“预检 → 生成文件夹 → 手工放产出 → 扫描”；
2. 对接真实服务时只改 `base-url` 与三个 `*-path`；
3. 若对端字段名不同，只需替换 `BatchImportClient` 实现，服务层不动。
