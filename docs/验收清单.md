## 公式与 ID

- [x] 含公式的字段在纵向视图有 `ƒ` 徽标与公式原文
- [x] `formula_json` 保存字段与公式的关联（`fields` / `managed` / `_unresolved`）
- [x] 同一 upload 重复提交同一 sheet → `DUPLICATE_IMPORT` 警告（`duplicateOriginalIdAction`）；重新上传同一内容视为新批次，不提示
- [x] 同一 sheet 内业务键重复 → `KEY_DUPLICATE` 警告「appears N times in the sheet」；跨批次重复不再提示
- [x] 只改公式缓存值（不改公式）→ Business Record Id 不变（`RowConverterTest`、`RecordIdGeneratorTest`）
- [x] 公式文本按**原文**入库（`=D2*E2`），只有参与 Business Record Id 哈希时才按 `app.ids.normalize-formula-refs` 掩码行号，因此重算可以还原单元格地址（`RowConverterTest.keepsRawFormulaTextAndNormalizesOnlyForHashing`）
- [x] 导入工作簿时保存不可变基线 `batches/{batchId}/source.xlsx`，读取前校验 `sha256`；复制失败只给 `BASELINE_MISSING` 警告
- [x] 导出前重算：基线为底层、当前用例值按 Excel 原生类型（日期=序列号、数值=double、布尔、文本）写回、公式原文照写，再求值回填；源文件缓存值陈旧或缺失时导出得到正确值（`ExportRecalcTest`、`WorkbookRecalculatorTest`）
- [x] 重算反映平台内编辑：改动输入字段后导出，依赖它的公式列随之变化（`ExportRecalcTest`）
- [x] 重算不修改基线文件本身（POI 在临时副本上工作，导出前后 `sha256` 一致）
- [x] 不支持求值的公式保留用例存储值并告警（`FORMULA_RECALC_WARNING` / `FORMULA_RECALC_INCOMPLETE`），基线缺失时 `FORMULA_RECALC_SKIPPED` 且导出照常完成
- [x] 导出界面「导出前重算公式」复选框（默认勾选），取消勾选则输出用例存储值
